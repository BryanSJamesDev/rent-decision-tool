# Project rules

- Every data point must carry its source (URL or record name) and the date it was retrieved.
- Never invent data. If a value is unknown, mark it "unknown".
- When sources conflict, record all values and flag the conflict. Do not silently pick one.
- Never run git commit or git push, and never add Co-Authored-By or any attribution lines. The user commits.
- Scope is about 5 hours of work. Prefer a small, complete tool over an ambitious unfinished one.
- Plain language, no em dashes.
